| Nome da Configuração                             | Padrão                                         | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------------------------------ | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hoodie.datasource.write.operation`              | upsert (Opcional)                              | Define se a operação será `upsert`, `insert` ou `bulk_insert`. Use `bulk_insert` para carga inicial e depois `upsert/insert`. O `bulk_insert` usa escrita baseada em disco para suportar grandes volumes sem cache. **Parâmetro:** OPERATION                                                                                                                                                                                                                                                                |
| `hoodie.datasource.write.precombine.field`       | ts (Opcional)                                  | Campo usado no pré-combine antes da escrita. Quando dois registros possuem a mesma chave, o Hudi escolhe o com maior valor neste campo (`Object.compareTo(..)`). **Parâmetro:** PRECOMBINE_FIELD                                                                                                                                                                                                                                                                                                            |
| `hoodie.combine.before.insert`                   | false (Opcional)                               | Se registros inseridos tiverem mesma chave, controla se devem ser combinados (desduplicados) antes de gravar. **Parâmetro:** COMBINE_BEFORE_INSERT                                                                                                                                                                                                                                                                                                                                                          |
| `hoodie.datasource.write.insert.drop.duplicates` | false (Opcional)                               | Se `true`, registros de entrada não sobrescrevem registros existentes com a mesma chave. **Depreciado a partir da 0.14.0**, use `hoodie.datasource.insert.dup.policy`. **Parâmetro:** INSERT_DROP_DUPS                                                                                                                                                                                                                                                                                                      |
| `hoodie.bulkinsert.sort.mode`                    | NONE (Opcional)                                | Modos de ordenação no `bulk_insert`. <br>• `NONE`: sem ordenação, mais rápido. <br>• `GLOBAL_SORT`: melhor tamanho de arquivo, custo de ordenação. <br>• `PARTITION_SORT`: ordena dentro da partição RDD. <br>• `PARTITION_PATH_REPARTITION`: garante que cada partição física seja escrita pelo mesmo executor (só se dados forem bem distribuídos). <br>• `PARTITION_PATH_REPARTITION_AND_SORT`: igual ao anterior, mas adiciona ordenação extra por partição Spark. **Parâmetro:** BULK_INSERT_SORT_MODE |
| `hoodie.bootstrap.base.path`                     | N/A (Obrigatório em bootstrap)                 | Caminho base do dataset a ser bootstrapado como tabela Hudi. **Parâmetro:** BASE_PATH. **Desde a versão:** 0.6.0                                                                                                                                                                                                                                                                                                                                                                                            |
| `hoodie.bootstrap.mode.selector`                 | `MetadataOnlyBootstrapModeSelector` (Opcional) | Define o modo de bootstrap: <br>• **MetadataOnlyBootstrap**: cria apenas metadados, depende da tabela original. <br>• **FullRecordBootstrap**: copia registros completos, equivalente a bulk_insert. <br>• **BootstrapRegexModeSelector**: seleciona partições via regex. **Parâmetro:** MODE_SELECTOR_CLASS_NAME. **Desde a versão:** 0.6.0                                                                                                                                                                |
| `hoodie.datasource.write.partitions.to.delete`   | N/A (Obrigatório em delete_partition)          | Lista de partições a excluir (separadas por vírgula). Aceita `*` como curinga. **Parâmetro:** PARTITIONS_TO_DELETE                                                                                                                                                                                                                                                                                                                                                                                          |
